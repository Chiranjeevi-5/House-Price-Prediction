# House Price Prediction using Linear Regression

## Project Overview
This project predicts house prices in Bengaluru using Machine Learning. A Linear Regression model is trained using property details such as location, total square feet, area type, number of bathrooms and balconies.

## Objective
To build a Machine Learning model that estimates house prices based on different property features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset
Bengaluru House Price Dataset.

Dataset source: [Kaggle - Bengaluru House Price Data](https://www.kaggle.com/datasets/amitabhajoy/bengaluru-house-price-data)

## Features Used
- Area Type
- Location
- Total Square Feet
- Number of Bathrooms
- Number of Balconies

## Project Workflow
1. Importing libraries
2. Loading the dataset
3. Exploratory Data Analysis (EDA)
4. Data cleaning
5. Handling missing values
6. Selecting input and target features
7. Train-test splitting
8. Data preprocessing using ColumnTransformer
9. Model training using Linear Regression
10. Model evaluation
11. Predicting new house prices

## Model Evaluation
The model is evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## How to Run the Project

1. Download or clone this repository.
2. Install the required libraries:

   `pip install numpy pandas matplotlib seaborn scikit-learn joblib`

3. Open the Jupyter Notebook.
4. Run all cells.
